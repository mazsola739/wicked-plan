# On the show

How every game was played on The Devil's Plan, one page per game, and one page per season for the
frame around the games. These pages are background only: the spec of our versions is in
[docs/games](../games.md), and nothing here ships with the web page.

Source: the NamuWiki episode guides and game-rules pages (English machine translation), recorded in
November 2026 in our own words, with no contestant names. Machine translation and gaps in the source
mean a detail can be wrong; check the **Gaps** list of a section before relying on it.
